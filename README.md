# AutoGen 多智能体旅行规划

输入一句自然语言需求，三个 AI 在群聊里轮流协作，最后交出一份逐日行程表。
需要你拍板时它会停下来问你。

```
python main.py "我国庆去诸暨玩，三天，两个人，预算 2000。"
```

不传需求就用内置的示例任务（成都三天两晚 4000 元）。

## 跑起来

依赖：**Python ≥ 3.12**（实测 3.14.4 可用）+ 下面三个包。

```bash
uv venv --python /usr/bin/python3.14     # 显式给系统解释器，理由见「出问题怎么办」
uv pip install "autogen-agentchat==0.7.*" "autogen-ext[openai]==0.7.*" "requests>=2.31"
```

配三个 key（优先级：环境变量 > `keys.py` > 项目根目录的 `.env`）：

```bash
cp keys.example.py keys.py    # 然后填 DEEPSEEK / TAVILY / AMAP 三个
```

各自去哪申请、有哪些坑（高德那个特别容易建错），都写在 [keys.example.py](keys.example.py) 里。

```bash
python main.py "我国庆去诸暨玩，三天，两个人，预算 2000。"   # 直接跑完整流程
python main.py --selftest                                  # 离线自测：不用 key、不联网
```

跑起来后：约两分钟终端不动是正常的（资料员在联网查，一轮要搜七八次）；然后它
**停下来问你**，打出审查员的问题清单——你敲一句话回答，带具体数字或动作
（「住宿砍到 250 一晚」比「再优化一下」有用），它继续跑；审查员说 `APPROVED` 就结束。

> 安全：`keys.py` 已在 [.gitignore](.gitignore) 中忽略、不会进 git。若曾把真实 key
> 填进文件并外传过，请到对应控制台轮换重置。

## 网页版

不想看终端的话，同一个流程有个网页界面。**双击桌面的「旅行规划」图标就行**——它会
起服务并自动打开浏览器。（重复双击不会起第二个服务，只会把浏览器指到已经在跑的那个。）

```bash
python launcher.py                   # 起服务，并自动打开浏览器
python launcher.py --demo            # 离线假数据：不用 key、不联网，几秒看完整个回路
.venv/bin/python make_shortcut.py    # 重建桌面图标（换了机器才需要）
```

**零新增依赖**（只用标准库），不用装 tkinter。WSL2 会把 localhost 转发到 Windows，
所以直接用 Windows 浏览器开 `http://localhost:8765` 就行——不用记 WSL 的 IP。

## 三个 AI 分别干什么

| 谁 | 干什么 | 手里的工具 |
| --- | --- | --- |
| **资料员** `researcher` | 唯一能上网的，负责查事实、把资料整理成清单 | 搜网页、读全文、算打车钱、列酒店 |
| **编排者** `planner` | 把资料排成逐日行程 | 一个都没有 |
| **审查员** `critic` | 挑错：时间冲突、绕路、超预算、编造 | 算账的，外加一个把你叫停的通道 |

**为什么只有资料员能上网？** 因为一旦编排者也能自己搜，它就不去问资料员了，三个 AI
立刻退化成三个各干各的、互不搭理的单个 AI。所以这不是权限设置，是这套结构能成立的
前提。想深究的话见 [docs/architecture.md](docs/architecture.md) 第 2 节。

## 哪些数据查得到，哪些查不到

一键旅行规划最容易让人失望的是「它到底能不能给我准数」。实测下来是这样：

| 数据 | 情况 |
| --- | --- |
| 高铁票、机票 | ✅ 查得到 |
| 景点门票 | ✅ 查得到，但得读整页——搜索引擎给的摘要常把价目表那截截掉 |
| 市内公交地铁费率 | ✅ 查得到费率，但要用里程才能算成总额，所以行程表里常写「待确认」 |
| **打车钱** | ⚠️ 能算出来，但**有约 18% 的偏差**，见下 |
| **酒店房价** | ❌ **查不到**，见下 |

### 酒店房价查不到，这不是没做好，是取不到

三个原因叠在一起：

1. **房价是按「日期 × 房型」在下单那一刻生成的**，网页上没有固定页面。
2. **订房网站要登录才显示价格。** 实测去抓携程的酒店页，返回的整个是一张登录表单，
   一行房价都没有。
3. **搜索引擎能搜到的中文房价页，大多是港台或境外站点**，报的是港币、美元、马币，
   而且那些是网站自己统计的「商圈均价」，不是某家酒店某两晚的真实价格。

所以行程表里的住宿金额只有两个来源：**你自己拍板的数**，或**按商圈价位区间估**。
看到「待确认」时那是诚实的空缺，不是它偷懒——你回一句「住宿砍到 250 一晚」，它就会
用这个数把账算完。

### 打车钱是估的，和当地实际收费可能有出入

打车金额来自高德地图，它用的是**通用计价模型**，不套用当地的运价文件。实测同一条路线
（诸暨站 → 五泄风景区）：高德报 71 元，而按诸暨政府公布的运价手算（含「超过 8 公里部分
加收 40% 空驶补贴」）是 86 元——**差 18%**。

所以行程表里这一项会带着一句「未套用当地运价文件，可能有出入」。它是估值，不是报价。

## 想改什么，动哪个文件

| 想改什么 | 动哪个文件 |
| --- | --- |
| 换模型名 | 设 `DEEPSEEK_MODEL`（环境变量 / `keys.py` / `.env`），不用改代码 |
| 换某个 AI 的性格、职责 | `docs/agents/*.md` §8 + `persona.py`（两处要一起改，自测会核对） |
| 加一个新 AI | `persona.py` + `main.py` |
| 加一个新工具 | `tools.py` + `persona.py` |
| 换搜索后端 | `tools.py` 里的 `search()` |
| 调轮数上限 / 最多问几次 | `main.py` 的 `MaxMessageTermination` / `MAX_HANDOFFS` |
| 换 AI 的说话顺序 | `main.py` 的 `GROUP_MEMBERS` |

最后几行是**连体改动**，改一处忘一处会静默退化成「跑到上限才停」。

## 出问题怎么办

先跑 `python main.py --selftest`——它不联网、不需要 key，能抓出大部分接线问题。

还不行就用 `--stage` 逐层排查，出问题时就按这个顺序往回退：

| 命令 | 验什么 |
| --- | --- |
| `--stage 1` | 模型连不连得上 |
| `--stage 2` | 只跑资料员，输出里有没有**真实可点的网址**——点开一个确认内容对得上 |
| `--stage 3` | 加上编排者，它有没有引用查到的**具体票价**而不是自己编 |
| `--stage 4` | 加上审查员，它有没有挑出**真问题**（只会说「行程很合理」就是失败） |

脚本化跑（不用手敲回答）：`--reply "回答"` 可重复给多次，第 N 次拍板用第 N 个。

**装依赖卡住不动**：别用 `uv venv --python 3.12`，它会去 GitHub 拉独立构建，网络不通时
表现为静默卡死（进程活着、什么都不输出、`.venv` 不出现）。显式给系统解释器路径就行。
